# Architecture Decision Records

ADRs capture decisions that materially constrain implementation.

## Status meanings

- **Accepted baseline:** use this design unless superseded.
- **Proposed baseline:** sufficiently specified for planning, but open questions remain before implementation.
- **Superseded:** replaced by a later ADR.
